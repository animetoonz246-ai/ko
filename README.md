# XPS Viewer (MIT)
Android Studio project: open XNALara/XPS binary .mesh and .xps models, apply .pose files, animate A<->B.
Build: open in Android Studio -> Build > Build APK(s).
Controls: drag = rotate, pinch = zoom. Folder -> pick the model folder. Pose A / Pose B -> pick .pose files. Play = tween A<->B.
Notes: textures png/jpg/tga supported (no DDS yet). First texture = diffuse. Max 128 bones on GPU.
